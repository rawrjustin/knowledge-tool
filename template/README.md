# Shaq Companion App

A modern, native macOS application bringing the "Shaq" persona to life.

## Features
- **Modern UI:** Built with SwiftUI, utilizing macOS 14+ translucent materials and animations.
- **Aesthetic:** Custom "Lakers Night" theme (Purple & Gold accents on dark mode).
- **Interactive:** Chat with the "Big Aristotle" (Mock AI tailored to the persona).

## How to Run

1. Open Terminal.
2. Navigate to the `ShaqApp` directory:
   ```bash
   cd ShaqApp
   ```
3. Run the app:
   ```bash
   swift run
   ```

## Development
The source code is located in `ShaqApp/Sources/ShaqApp`.
- `ShaqApp.swift`: App Entry point.
- `ContentView.swift`: Main UI and Chat Interface.
- `ShaqLogic.swift`: Persona logic and response generation.
- `Theme.swift`: Color palette and fonts.
